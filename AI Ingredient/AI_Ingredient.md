Q) **What is Instructions.md file and prompt.md ? How it is related to each other and what differ them ?**

Ans: In GitHub Copilot, both `copilot-instructions.md` and `.prompt.md` files are <mark>**markdown-based configuration tools used to customize AI behavior.**</mark> However, they serve completely different purposes in how they are triggered and applied.

The core difference is that `instructions` are **"always-on" global rules automatically injected into every request**, while `prompts` are **"on-demand" templates that you manually call when needed.**

##  Types of instructions file 
1. **Repository-wide instructions:** These are general instructions that apply across the repository, it is were we define the project overview, stack, standards. Do this one First. It will be injected in every request.
 `.github/copilot-instructions.md`
2. **Path-specific instructions:** These allow us to give different instructions to different parts of the codebase. It is like a rules that will be `appliedTo` specific files. `.github/instructions/*.instructions.md`
3. **AGENTS.md:** "This provides instructions intended for AI agents and can be shared across agentic tools. It is a cross-tool standard +monorepo nearest wins it is like a README file for Agents.

## Prompt File
Unlike always-on instructions, prompt files are reusable prompts for specific tasks.
| Instructions                       | Prompt                          |
| ---------------------------------- | ------------------------------- |
| "How should you behave?"           | "What task should you perform?" |
| Persistent                         | On-demand                       |
| Project/team conventions           | Specific reusable task          |
| Automatically applied within scope | Invoked when needed             |


Q) **What is Agentic AI ?**

Ans:  In simplest terms, Agentic AI refers to AI systems that can autonomously pursue a goal by reasoning about what needs to be done, deciding on actions, using tools, observing results, and adapting their next steps.

A multi-agent system is one approach where multiple specialized agents collaborate to achieve a larger goal.

```
                    Goal
                     ↓
          ┌────────────────────┐
          │   Agent / Planner  │
          └─────────┬──────────┘
                    ↓
        ┌───────────┼───────────┐
        ↓           ↓           ↓
   Research      Coding       Testing
    Agent         Agent        Agent
        └───────────┼───────────┘
                    ↓
                  Result
```
